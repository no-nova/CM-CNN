# 1200 张数字：脉冲增强与类别原型 WTA

## 运行与结果

```bash
npm run snn:prototype -- --out experiments/snn-prototype
npm run snn:prototype -- --quick --out .diag-state/prototype-smoke  # 仅流程烟测
npm run snn:predict -- --model experiments/snn-prototype/class-prototype.cm.json --index 1222 --mode cm
npm run test:snn
```

本次完整实验的种子为 77；`--seed` 可更换泊松事件、样本顺序和 CM 身份哈希的种子，**不会改变卷积核初始化种子或数据划分**。默认运行在本环境约 19.5 分钟；不等于部署速度。完整原始回执是 [`experiments/snn-prototype/results.json`](../experiments/snn-prototype/results.json)，包括各图像索引、类别响应矩阵、分通道发放率、各类准确率和成本。两个冻结后的 CM 模型：[`intrinsic-control.cm.json`](../experiments/snn-prototype/intrinsic-control.cm.json) 和 [`class-prototype.cm.json`](../experiments/snn-prototype/class-prototype.cm.json)。

| 模型 / 指标 | 训练 3 视图 | 验证稠密 | 测试稠密 | 测试 CM 70% | CM 70% 总算术比 |
|---|---:|---:|---:|---:|---:|
| 稳态阈值对照 | 97.1% | 87.5% | 98.0% | 95.5% | 64.4% |
| 类别原型 WTA | 97.6% | 89.0% | 98.0% | 96.0% | 62.8% |

两个模型都在训练上明显高于验证，原型模型训练原始视图为 98.0%、验证为 89.0%；增强和正则化**没有证明消除了过拟合**。验证只 200 张，89.0% 比对照高 3 张，不能作为可靠改进。测试集两组同为 196/200；测试明显高于验证，须警惕顺序切分与数据分布差异，不能把 98% 外推为稳定性能，也不能直接和旧的 91% 比较（划分、训练规模、桥接布局都变了）。

原型模型测试的无损 event 为 98.0%、总算术比 72.4%；CM 70% 为 96.0%、62.8%（相对稠密省约 37.2%）；CM 50% 为 90.0%、46.8%（省约 53.2%）。因此本次尚未同时满足 **≥92% 和省 50%–70%**。同一 70% 预算的随机门控得到 97.5%、55.6%，本次 CM 并未优于随机门控；不能据一次 200 图结果断言普遍排序。

仅按每类三个通道在一张图上的**总发放数**直接选类，原型模型的验证 / 测试为 **12.5% / 12.0%**（对照 6.0% / 14.0%）。这是用于检查通道专属性的粗略指标，不等价于线性读出；它不支持宣称已长出可靠的类别专属笔画检测器。两层测试集均无平均发放率低于 0.001 的通道；有活动也不等于检测器有意义。L2 权重 RMS 改变量为 0.01422，记录到 10,800 次真类赢家更新、41,648 次其他类抑制、零次目标通道无脉冲；不代表所有核学到了有效笔画。

## 切分、增强与不泄漏约束

- 1797 张原图：训练索引 `0–699`, `920–1199`, `1420–1639`（1200）；验证 `720–919`（200）；测试 `1220–1419`（200）；余 197 未使用。索引在代码中校验唯一且三集合不交，测试另检查训练与验证/测试不存在像素完全相同的原图。
- 这些验证/测试区间没有用于先前报告的 500/200 实验；但本实验训练集包含一部分**旧实验**的评估图，故绝不能把两次的分数直接作为同一测试集对照。划分不是随机分层或按书写者独立；各类计数可在回执中核对。烟测和单元测试使用不同的 1700–1719 区间，不消费本实验验证/测试图。
- 将 8×8 图最近邻放大到 24×24，按原图和种子产生 20 步泊松事件。训练每张图有三种视图：原始事件、`dx=-1, dy=+1`、`dx=+1, dy=-1`；两种位移视图的每个事件各有 15% 概率向前或向后抖动一个时间步。位移发生在 **24×24 事件画布**，不是原 8×8 的整像素；出界事件被丢弃、碰撞合并。验证/测试只用原始事件流。3600 是同一批 1200 图的相关视图，**不是 3600 个独立原图**。

## 网络、学习与计数

先从相同随机卷积核出发，使用训练集的 1200 条原始事件流、无标签地更新 L1/L2 发放阈值；之后冻结阈值。两组都使用修正后的层间布局和相同阈值、相同事件视图与读出：对照不改卷积权重；实验组仅在 L2 做一遍带标签的局部学习，L1 权重仍为随机初始化（仅阈值自适应），**没有事先训练读出层来指导突触**。因此本实验尚未实现 L1 卷积核的学习。

L2 通道 0–29 固定分为 10 类 × 3，30–31 为保留通道、不做原型更新。每个样本与视图分别统计每个通道、每个位置的整段发放次数：真类三个通道各取最强位置（同分取最先位置），有发放则在该位置按同时刻的 L1 前脉冲与 L2 后脉冲作中心化 Hebbian 更新；其余类中最强位置发放次数超过 30 个已分配通道均值的，作强度为 0.25 的反向更新。每个卷积核保持原范数并更新证书缓存；没有 L2 发放的赢家不能更新。权重学习率 0.03；标签只用于训练，不送入预测。这个方法是样本末的局部相关 + 类别调制，不是时差 STDP、不是端到端反向传播；核范数约束是工程性共享归一，也不能据此声称生物真实性。

学习结束后，两组分别**只训练一个**有监督 softmax 读出（3×3 池化、432 维、400 epochs、L2 λ=0.1），读出本身仍使用监督梯度更新；错误不反传到 SNN。若“完全不用反向传播”要求连读出都不得使用梯度，本实现尚不满足，需另做无梯度读出对照。新实验将每样本正则项除以训练样本数，使有效 λ 不随视图数翻倍；旧实验的默认读出实现保留原口径。CM 教师只用 1200 条未增强训练流训练，之后参数与历史冻结；两个模型均保存 CM 状态与桥接标志，测试用重新加载的模型运行。

旧 `Net` 的层输出是位置优先交错，L2 卷积输入却按通道优先读取。新实验启用显式位置交错→通道优先转换；旧模型仍按旧布局执行，以免悄悄改变历史回执。桥接复制次数被计入新实验和 `snn:predict` 的总算术模型，并同样计入稠密分母；它只是元素复制计数，未实测访存、设备延迟或能耗。IP 前向计数乘加 26,582,716,160，原型阶段前向计数乘加 78,380,244,128；局部更新、读出训练、CM 教师和数据增强未计入推理比，局部更新的操作数尚未计量。未测 GPU/真实运行加速。

下一步应在新的多划分或书写者独立测试上验证；用训练内验证对学习率、抑制强度、阈值和类簇竞争做消融，并比较无增强 / 单独位移 / 单独时间抖动。当前对照只隔离了原型更新，没有隔离“1200 张”和“增强”各自带来的作用；也没有通过核可视化或干预证明学出了笔画检测器。
