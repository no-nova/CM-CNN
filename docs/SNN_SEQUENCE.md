# 零语料启动的在线脉冲字节生成原型（v1 历史记录）

> 现在 `snn:sequence` 默认运行 v2：使用多尺度状态、配对支持集截断及额外消融。最新运行方式和结果见 [SNN_SEQUENCE_V2.md](SNN_SEQUENCE_V2.md)。本页记述旧版数值与原理，不代表当前默认程序的输出。

这是一个**实验性、字节级的序列生成器**，不是预训练大语言模型。每次新建模型时 CM 表全空、脉冲膜电位/历史为零，从输入的第 0 字节起逐位先预测再学习；生成时在模型条件概率上采样。没有加载任何从语料学到的权重、词表或语法规则。不过“零先验”仅指**没有预训练语料和数据训练过的参数**：仍有人工选定的结构、阈值、随机连接、平滑和混合规则，不能声称数学上没有归纳偏置。

## 历史模型与当前运行方式

## 实测：4 KiB 在线输入，2 KiB 留出

| 输入 | 方法 | 从第 0 字节在线预测（bit/byte） | 留出：CM 冻结、真实前文推进状态 | 留出：逐字节在线更新 |
|---|---|---:|---:|---:|
| Shakespeare 前缀 | 脉冲 + CM | 4.045 | 3.853 | 3.723 |
| Shakespeare 前缀 | 不使用脉冲上下文的 CM | **4.004** | **3.795** | **3.638** |
| 代码 `scripts/diag/inspect-structure.mjs` | 脉冲 + CM | 4.210 | 4.009 | 3.621 |
| 相同代码 | 不使用脉冲上下文的 CM | **4.149** | **3.890** | **3.441** |

更低的 bit/byte 表示对真实后续字节给出较好的概率，8 是每位独立 50/50 的均匀字节基线；这是理论对数损失，**不是实际压缩码流、语义正确率或生成质量评分**。留出段采用 teacher forcing：每个字节先评分，再将其真实值送入上下文；冻结版本不更新 CM 表，在线版本评分后更新表。两个版本都不靠留出数据进行初始训练。训练和留出是一段连续文本的前后段，不是独立文档或跨领域泛化测试。

目前两个例子中，加入脉冲上下文均比纯 CM **略差**，尽管脉冲确实参与预测。因此尚未证明脉冲状态有用；不能将 CM 已有的 n-gram 学习效果归功于 SNN。莎士比亚训练期间前 512 字节平均为 4.645 bit/byte，最后 512 字节为 3.797，表明该流上出现在线适应，但窗口内容不同，不能单凭这一点归因或预测其他语料表现。64 个神经元处理 4096 字节共产生 56,543 次脉冲；发放本身并不证明学到语言。

三份 512 字节莎士比亚生成样本中可打印 ASCII 比例约 95.9%–96.9%，但三份都不是合法 UTF-8，分别含 12、14、13 个替换字符。样本能模仿一些局部短词、标点或角色名碎片，但还有大量拼写、语法错误和乱码，**远不能可靠续写有意义的文章**；代码样本也未达到可运行代码的程度。结果见 [`experiments/snn-sequence/results.json`](../experiments/snn-sequence/results.json) 与 [`experiments/snn-sequence-code/results.json`](../experiments/snn-sequence-code/results.json)。

## 因果流程与模型

1. 一个新模型的五个散列双计数表是空的，采用 `(n1+1)/(n0+n1+2)` 的对称平滑初始值 0.5。读取每个字节时，按高位到低位逐位先计算概率并累计 `−log2(P(bit))`，然后只用实际观察到的那一位更新表，再前进到下一位。任何预测只能看到先前字节及当前字节**已观察**的高位。
2. 四路 CM 以当前位前缀为上下文，分别结合最近 0、1、2、3 个完整字节；按桶内样本数进行层级插值，桶计数到 1024 时减半。第五路以当前位前缀和最近一次 LIF 群体活动的 8 位签名为上下文，以最大混合权重 0.35 叠加。哈希碰撞、平滑和固定规则均是工程性近似。
3. 每个完整字节映射到 8 个二值输入通道，驱动一个固定拓扑的 64 神经元循环 LIF 网络，膜电位衰减、过阈发放并重置。固定伪随机连接由种子生成，没有数据训练过的权重；每组 8 神经元的脉冲数是否达到 2 构成一位签名，供下一个字节的 CM 使用。SNN 每字节推进一次，而非模拟字符神经语言模型的多步编码。该网络只提供上下文，**不学习突触权重**；在线学习发生在 CM 计数表。
4. 采样时每一位按预测概率独立施加 logit 温度并抽样，形成完整字节后推进脉冲状态和历史。默认冻结 CM，不学习生成字节；不做 ASCII、UTF-8、词表、语法或质量过滤。生成可能输出无效编码，且不保证忠实续写或复现真正的后续内容。

纯 CM 对照保留相同的字节上下文、训练与采样规则，但不把脉冲签名混入概率（当前实现仍推进了脉冲状态，因此不是速度优化对照）。实际结果受固定网络拓扑、短上下文、混合权重与语料影响；本次没有跨语料调参、异常检测、生成质量人工盲评或算力/能耗实测。

## 数据来源

`data/tinyshakespeare-prefix.txt` 是 [karpathy/char-rnn 的 tinyshakespeare 文件](https://github.com/karpathy/char-rnn/blob/370cbcd448eb7daf32f21a6be560b70e0b33c4e3/data/tinyshakespeare/input.txt) 的前 6144 个原始字节（开头为莎士比亚戏剧对白）。上游整个输入的 Git blob 为 `7dcb3a2d4cc3b48b6283dd46870bfeb78f88aac9`，SHA-256 为 `86c4e6aa9db7c042ec79f339dcb96d42b0075e16b8fc2e86bf0ca57e2dc565ed`；项目中摘录的 SHA-256 为 `0bec05d7c7070f01405c2f8697787196fef527aeee8bff0d3fb81e096eb4157b`。代码样本为本仓库原有的 `scripts/diag/inspect-structure.mjs`，文件及精确训练/留出哈希见结果文件。这里“未见过”是指这些字节对**新建的空模型**未预训练，并非保证它们对所有人或其他模型都未知。

下一步需要在多篇独立文本与二进制流上重复，验证在线异常分数；设计只基于过去数据的脉冲状态学习、脉冲消融及边际信息量测量；对有效编码与自然语言连贯性分别做明确的评估。当前尚未实现这些能力。
