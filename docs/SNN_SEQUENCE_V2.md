# 多尺度脉冲状态与零预设支持集采样

## 结果概要

与上一版使用完全相同的前 4096 字节在线训练、后 2048 字节留出测试。概率损失为 bit/byte，越低越好；留出为真实前文逐字节推进状态，但不更新概率表。四个模型从空表开始、预测后才学习，没有共享训练好的参数。

| 输入 / 方法 | 训练流先预测 | 留出冻结 | 留出在线更新 |
|---|---:|---:|---:|
| Shakespeare：原 64 神经元 Spike + CM | 4.0451 | 3.8528 | 3.7231 |
| Shakespeare：原纯 CM | 4.0041 | 3.7945 | 3.6381 |
| Shakespeare：多尺度 Spike + 补充专家 | 3.9674 | **3.7374** | 3.5870 |
| Shakespeare：同样的补充专家，脉冲相位固定 | **3.8963** | **3.6647** | **3.5274** |
| 代码：原纯 CM | 4.1491 | **3.8898** | **3.4410** |
| 代码：多尺度 Spike + 补充专家 | **4.1388** | 3.8937 | 3.4632 |
| 代码：同样的补充专家，脉冲相位固定 | 4.1131 | 3.9095 | 3.4971 |

莎士比亚的目标数值上成立：3.7374 **严格低于** 3.7945，差 0.0571 bit/byte。但相位固定消融反而更好，说明不能把这次提升归因于脉冲动态；新增的带不同平滑方式的额外上下文专家本身就是混杂因素。在代码留出集上，多尺度比纯 CM 略差 0.0039 bit/byte，但优于固定相位消融。两份文本太少，且这两个留出区先前用于旧模型报告，不能当成从未看过的独立盲测；尚不能断言普遍增益或真正的长程互补信息。

原纯 CM 在新旧程序中的先预测和留出 bpb 一致，回归测试还逐个比较了 CM 的计数表与字节历史。上版的随机脉冲实现采用固定 0.35 混合权重，**没有训练 Mixer 权重**；对照结果不能证明此前下降由权重训练开销引起，可能来自上下文稀疏或其他因素。

## 采样：同模型、同种子和温度的配对比较

各生成 512 字节，种子 17 / 23 / 31，温度 0.8。两种变体都从完全相同的 4 KiB 训练模型生成；每位都消耗同一序列的随机数（路径变化后上下文会不同），生成字节不更新概率表或支持集。

| 输入 | 截断 | 全部三个样本的未见训练字节数 | 合法 UTF-8 样本数 | 平均未见训练三字节片段比例 |
|---|---|---|---:|---:|
| Shakespeare | 无 | 30 / 38 / 29 | 0 / 3 | 61.1% |
| Shakespeare | 已见支持集 | **0 / 0 / 0** | **3 / 3** | 51.8% |
| 代码 | 无 | 15 / 27 / 19 | 0 / 3 | 60.8% |
| 代码 | 已见支持集 | **0 / 0 / 0** | **0 / 3** | 57.3% |

训练中的 52 种莎士比亚字节恰好都是合法的单字节 ASCII，因此截断后这三份样本都是合法 UTF-8。代码训练前缀包含非 ASCII 字节：单个字节已见不代表组合符合 UTF-8，截断后仍有替换字符。片段比例只用来粗查分布外组合，不是质量或连贯性评分；正文仍有大量错词和不通顺。支持集方法保证在非空支持集下不产生训练中未见的**单字节**，不保证未见 n-gram 或 OOD 雪崩消失，也不能保证编码合法、更好的语义或执行正确性。

## 结构设计

- 原纯 CM 的 0–3 阶字节上下文、计数更新和原始预测代码不变；结构网络仅作为额外专家调整该概率，不覆盖或拆分原表。原模型输出为 `p`。
- 12 个固定参数 leaky integrate-and-fire 神经元每个字节推进一次：8 个较快单元根据该字节各位活动更新并输出脉冲；4 个慢单元使用 0.75、0.875、0.9375、0.96875 的衰减，接收“当前字节等于过去最常见字节”的事件。该频次用过去字节在线统计，满 8192 次老化；前 16 次不生成该事件。没有预设空格、换行、标点、ASCII、词表或任何语言类别。当前两份文本中，训练结束时最常见字节恰好是空格，但这种代理并不能识别一般语言的词边界，更不能单独追踪标点或换行。
- 前一个字节、当前字节已知的位前缀，分别组合慢单元量化膜电位和快单元的发放位模式，得到两组散列补充上下文。每组计数的预测向原始 `p` 收缩：`q=(n1+24*p)/(n+24)`；最终输出 `p + 0.35*(q_slow−p) + 0.15*(q_fast−p)`。未命中的专家桶严格退化为 `p`；两组表只在真实字节的对应位预测之后更新，没有反向传播或预训练权重。仍有固定衰减、阈值、散列、混合系数等归纳偏置。
- 固定相位消融拥有**同样的两组专家表和混合系数**，但把快慢状态输入常量化；因此特别有助于区分额外专家和平衡脉冲状态的贡献。它不抹去上一字节上下文。
- 为保留旧 CM 的实现与旧状态兼容，内部复用的旧 CM 对象仍会推进原 64 神经元 LIF，但在纯 CM 和新版中它的脉冲**不参与预测**；新增的实际结构信号来自 12 个单元。没有测算力、延迟或能耗，不能据此称其更高效。

## 尾部截断的严格定义

只存一个 256 位的训练期间已观察字节支持表（实现为 256 字节标志），不存文本；每个候选位根据当前已采样前缀查询这个支持表：若 0 和 1 中只有一个分支能到达至少一个已见字节，就将另一个分支概率置零；两支都有支持则不截断，两支均无支持（例如模型还未读到任何字节）则回退原预测。该机制是**支持集截断**，不是概率累积式 nucleus；它没有字节值、UTF-8 或词典规则。它允许任何历史见过的 0–255 值，但也会永久禁止生成目前没出现过的新字节，直到之后在真实输入中见到它；不适合需要产生新符号的任务。截断只用于采样，bpb 评估使用原概率，无需面对被置零的测试分支。

## 使用和复现

```bash
# 同时输出无截断和已见支持集截断两组配对样本
npm run snn:sequence -- --out experiments/snn-sequence-v2
npm run snn:sequence -- --input scripts/diag/inspect-structure.mjs --out experiments/snn-sequence-code-v2

# 继续在线学习可选的真实字节输入，然后从 v2 模型生成；默认使用支持集截断
npm run snn:sequence-resume -- --model experiments/snn-sequence-v2/model.json \
  --input path/to/more.txt --support observed --out experiments/my-resume
# --support none 关闭截断；省略 --input 直接采样。
```

`model.json` 是训练后 v2 模型；`cm-only-model.json` 为原纯 CM，`constant-phase-model.json` 为消融。各随机种子的 `.bin` 是原始字节，`.txt` 仅为替换无效字节后的预览。`model-after-input.json` 不含采样历史；`model-after-generation.json` 保留采样后的脉冲与字节上下文，但不把生成字节加入 CM 训练或支持集。旧版 v1 模型仍可用 `snn:sequence-resume` 加载，但没有支持集状态，默认不截断；不能对它指定 `--support observed`。

实验结果与样本：[Shakespeare](../experiments/snn-sequence-v2/results.json)、[代码](../experiments/snn-sequence-code-v2/results.json)、[截断样本](../experiments/snn-sequence-v2/generated-17-observed-support.txt)。数据来源和上一版详见 [SNN_SEQUENCE.md](SNN_SEQUENCE.md)。下一步应在未复用文档、其他语言与二进制流上重新测，另做快/慢分支、相位桶和额外专家的独立消融；在不引入编码假设的前提下针对字节**序列**而非单字节支持设计低成本门控。
