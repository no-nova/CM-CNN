# Stream Agent 与类增量实验

## 运行

```bash
npm run snn:stream -- --out experiments/snn-stream
npm run snn:stream -- --quick --out .diag-state/stream-smoke  # 小样本流程测试，非跑分
npm run test:snn
```

默认依赖第一阶段的 `experiments/snn-prototype/intrinsic-control.cm.json`。完整报告为 [`experiments/snn-stream/results.json`](../experiments/snn-stream/results.json)：1200 条逐样本轨迹包含预测、真值、累计先验准确率、熵、惊奇度与更新系数。输出还包含两组最终 Agent 状态 `baseline.agent.json` / `entropy-gated.agent.json`，它们引用同一特征模型并记录其 SHA-256。可通过 `--model`、`--seed`、`--out` 指定模型、阶段内打乱种子和输出目录；改变种子不会改变 SNN 权重、已编码事件种子或数据划分。

模型可以对指定数字图像做一次先验预测：

```bash
npm run snn:stream-predict -- --state experiments/snn-stream/entropy-gated.agent.json --index 1700
```

默认是只读预测：不修改 CM 或读出；连续预测不会推进上下文。若确实拿到了这个样本的真实标签，可在**复制的状态文件**上显式反馈并原子写回：

```bash
cp experiments/snn-stream/entropy-gated.agent.json .diag-state/my-agent.json
npm run snn:stream-predict -- --state .diag-state/my-agent.json --index 1700 --label 3 --update
```

`3` 只是用户反馈示例，不保证是该图的真实标签。预测先于反馈计算，程序不从数据集自动读取真值参与训练。每次更新会改变模型；不要拿评估集反馈来做无泄漏评估。Agent 状态不包含 SNN 权重，必须保留文件中引用的特征模型及其路径；文件摘要不符会拒绝运行。快照只允许在反馈完成后生成，不含待反馈样本；一次只能有一个未反馈样本。CLI 不支持并发写同一个状态文件，调用方应串行化。当前接口为受控实验/单样本工具，不是实时服务或自动标签系统。

## 实验结果（单次 seed 77，10 类始终共同竞争）

| 指标 | 普通在线线性层 | CM 熵门控线性层 |
|---|---:|---:|
| 0–4 阶段逐样本先预测准确率（594 张） | 60.4% | 64.0% |
| 5–9 阶段逐样本先预测准确率（606 张） | 54.1% | 56.4% |
| 全流逐样本累计准确率（1200 张） | 57.3% | 60.2% |
| 第一阶段后旧类测试（103 张） | 91.3% | 82.5% |
| 第二阶段后旧类测试（103 张） | **0.0%** | **0.0%** |
| 旧类遗忘（第一阶段后减第二阶段后，百分点） | 91.3 | 82.5 |
| 第二阶段后新类测试（97 张） | 78.4% | 84.5% |
| 第二阶段后全部测试（200 张） | 38.0% | 41.0% |

第一阶段后，新类准确率均为 0%，因为模型尚未获得这些标签；它们仍参与输出竞争。验证集上，旧类准确率分别从 87.3% / 82.4% 降至 0% / 0%，新类分别为 74.5% / 75.5%。各类分子分母在结果文件中。**结论是两组都严重灾难性遗忘；本次 CM 熵门控没有保护住旧类。** 门控旧类的下降幅度较小只因为其初始分数较低，不能视为改善；流式和新类的差距是单次对比，不能推广。

本实验用的是第一阶段**仅无标签阈值适应**得到的 `intrinsic-control` SNN，而不是监督训练的类别原型 SNN。它的随机卷积核固定，阈值曾在本实验全部 1200 张流图（包括未来 5–9）上无标签适应；因此这不是从全新未知输入开始的严格零预训练/因果表征实验。两个 200 图验证和测试集不参与这次模型更新，也不在该 SNN 阈值适应的 1200 图中，但这些数字是此前实验使用过的保留集，并非项目级全新盲测。数据按原始索引块切分，非按书写者分组；仅一次流顺序、一个初始化，样本量也小。训练、验证、测试索引均在回执中。

## 先预测、后学习与 CM 定义

特征提取使用冻结 SNN 的**无损 event 模式**、20 步、3×3 池化的 432 维脉冲特征；执行时预先缓存特征仅为公平对照和实验加速，SNN 完全冻结，特征不依赖标签或其他样本。丢弃 checkpoint 中原来的监督读出；两个 10 类线性 softmax 读出均从零权重开始，输入逐样本 L2 归一。0–4 和 5–9 各在阶段内固定种子打乱，一张图只出现一次。每张样本**先由两组各自预测并计入准确率**，随后提供真实标签，分别更新一次读出；最后更新门控组的在线特征 CM。评估过程既不更新读出，也不更新 CM。没有样本回放、类别掩码、旧类数据或参数冻结。

普通线性层用每张样本标准的在线 softmax 梯度更新，学习率 0.3。门控组更新公式相同，学习率乘以实时系数：

- 每个归一特征按 `x[j] > 1/sqrt(432)` 二值化；一个 `CounterModel` 用特征索引作上下文，另一个用索引及**前一张流图**的对应位作上下文。两路预测概率等权混合，夹到 `[0.01, 0.99]`。
- 在当前样本学习之前，计算每特征平均二元预测熵 `H`（bit）及观察值的平均自信息惊奇度 `S`（bit），取 `N=min(1,S/2)`。
- 错误预测时系数 `0.5 + 0.5*N`；正确时为 `0.05 + 0.2*H*N`。门控不是学习出的控制器，也不保证保留旧类；比较同时改变了更新幅度/频率效应，不能单独证明 CM 的因果贡献。
- 完成读出更新后才用这张图的二值特征更新计数模型及上一样本上下文。两个阶段间不重置 CM 或读出。模型是在线适应的轻量上下文概率混合器，并非第一阶段纤维块脉冲 CM 预测器；这里的 H 是**特征位的预测熵**，不是分类 softmax 熵。预测错误与惊奇度只控制读出更新，不更新 SNN 卷积核。

本次第一/第二阶段平均 H 为 0.341 / 0.348 bit，平均 S 为 0.320 / 0.323 bit，平均门控系数为 0.248 / 0.287。主干特征的所有流样本都非零。这个实验未启用近似 CM 纤维门控，也未测训练或推理耗时、算术/能耗；因此不能据它声称第二阶段节省了计算。线性层仍使用梯度，只是没有反向传播到 SNN。

## 下一步

在验证集上预先选择并记录多种固定流顺序和超参数，用全新、按书写者隔离的测试集验证；加入同等计算量的随机/常数门控及不同学习率对照，排除单纯缩小学习率的效果。若目标是保留旧类，应尝试有明确内存/计算账本的小规模重放或类条件保护，再与无重放基线比较；也应做严格因果预训练消融。当前没有实现这些改进，也没有进入第三阶段。

## 类别隔离与原型的后续实验

三个流顺序种子的 NCM 和原型锚定读出结果及严格冻结、跨类竞争诊断见 [SNN_CONTINUAL.md](SNN_CONTINUAL.md)。两者第二阶段后平均旧类测试准确率分别为 71.8% 和 70.2%，而两种原 Softmax 对照为 0%；旧行不变并不意味着新旧竞争下没有遗忘。
