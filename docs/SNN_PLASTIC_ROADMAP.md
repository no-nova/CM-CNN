# CM-SNN 接手：局部可塑性与后续路线

本实验不改变 UCZ 编解码路径。第一阶段仍在研究中，**尚未达到 92%–95%+**；第二、第三阶段尚未实现。本页的结果是实际运行记录，不是预期指标。

## 第一阶段：已经实现什么

`src/lib/snn/plastic.ts` 在已有 LIF 卷积网络外提供按样本在线更新：每步统计突触前输入与突触后发放；同一位置如果多个通道发放，用循环起点选一个赢家，只有赢家的感受野参与局部相关统计。样本结束后，每个有获胜的卷积核朝其获胜时的平均二值输入移动，做中心化以保留正负权重；另按每个通道的真实发放率调节该通道阈值，并限制最大偏移。L1、L2 都用这一规则；它不读取标签，也不计算或反传梯度。

这是**同一步相关性 + WTA 的 Hebbian 原型**，不是按前后时差实现的 STDP。竞争只影响学习，**不会抑制前向脉冲**；权重每张图结束后更新，不是每个时间步改写。阈值属于网络的持久状态，样本间膜电位重置，但阈值不重置。更新后重建证书上界缓存。尚未证明学出了边缘或笔画检测器，也未验证特征多样性。

### 可复现对照

```bash
npm ci
npm run test:snn
npm run snn -- --plastic --quick              # 仅烟测，不作准确率结论
npm run snn -- --plastic --json experiments/snn-plastic-digits.json
# 参数实验（应先预留验证集，不能根据最终测试集挑选超参数）
npm run snn -- --plastic --plastic-lr 0.01 --target-rate 0.05 --threshold-lr 0.05 --max-offset 0.4 --epochs 1
```

完整默认运行在本环境耗时约 6.4 分钟。记录：[`experiments/snn-plastic-digits.json`](../experiments/snn-plastic-digits.json)。`--ntrain`、`--ntest`、`--steps`、`--seed` 可调整。默认种子 1592594996；图像切分保持历史基准：训练原始索引 0–499、测试 1477–1676，共 500/200；顺序切分，**并非多种子或书写者独立评估**。另修复了大训练集时旧切分偏移环绕进入训练集的问题；历史 500/200 索引不变。

两组使用完全相同的数字及泊松输入事件、形状（16/32 通道，L2 fanin 400）、3×3 池化、线性读出、CM 教师与 group=8。随机组不学 SNN；可塑组仅用训练集做一轮稠密无标签局部更新。之后冻结 SNN，**分别在各自的稠密训练特征上**训练相同的有监督 softmax 线性读出和稠密教师 CM，再在未参与任何训练的测试集评估。读出使用梯度更新，但误差**不反传到 SNN**；因此不是整个系统完全无梯度。所有门控共用各组的稠密读出，不对门控重新训练。CM 教师训练和线性读出训练不是流式测试。

该次测试随机组和可塑组准确率都为 172/200；不能据此宣称可塑性提高了准确率。可塑组在 CM 70% 下总算术比相对稠密降低约 68.3%，相对本组无损 event 降低约 7.6 个百分点；但发放率下降约 92%，值得检查是否出现通道沉默或特征退化。对照也包含同预算随机门控（可塑组 85.0%、总算术比 30.3%）；两者准确率差在 200 样本上不能作为稳健优势结论。

总算术比沿用原项目的 JS 标量**计数模型**：推理的卷积乘加 + 盒查询/选取 + 预测器估计操作数，除以同组稠密推理乘加；不是墙钟速度、能耗或 GPU 加速。它不含训练，也不含实际内存访问。可塑训练仅稠密前向已花费 15,449,760,000 次计数乘加，局部统计、权重/阈值更新和上界重建的成本**尚未计量**；CM 教师和读出训练同样不计入推理。仅比较推理不能宣称端到端省 68%。CM 使用旧的单标量基础阈值构造膜电位特征，未显式编码每个通道的稳态偏移；实际前向及强制计算则使用通道阈值。event 的逐脉冲无损性在本次实验与测试中均检查。

建议下一步先划出独立验证集，做多种子和学习率/阈值/单层与双层消融，量化逐通道发放、核多样性、L1 核可视化与 L2 笔画响应，并与仅改阈值、仅改权重的基线比较；只在参数固定后评估保留的测试集。目标是同时达到精度和算术指标，而不是用稀疏化替代精度。还需测量局部更新及在线 CM 训练成本。

## 第二阶段：待实现的前序和增量学习

- 定义逐样本 `predict → 记录 → 获标签 → 更新`，冷启动也计入准确率；不能先训练或根据该样本的标签选门控。分别记录整体、滑动窗口、按类和冷启动指标，确保顺序可复现。
- 0–4 后 5–9 的任务需要固定任务边界、类顺序和评估协议：报告各阶段各类准确率、旧类遗忘、新类学习、总算术和更新成本；最后对同一全类测试流比较。
- 在相同特征、同样训练样本和预算下比较普通在线线性读出、无 CM 门控的可塑模型及 CM 惊奇度/熵门控。必须说明是否允许回放、样本是否有标签、类边界是否可见；把门控指标与真实遗忘区分，不预设能抵抗遗忘。
- 消除当前稠密教师阶段，验证 CM 自训练的偏差、冷启动、状态重置及成本；测试无未来信息泄漏。

## 第三阶段：待验证的序列与跨模态

先在 1D 字节流或时间序列建立严格的下一步预测与前序异常检测，再增加在线生成。需要固定编码方式、字节/时间点的预测时序、异常标签和分布突变协议，对照现有 UCZ CM 或简单在线基线；报告码长/预测损失、异常检测指标、计算成本及生成评估。不能把本次图像分类的结果外推为通用智能能力。

## 后续训练：独立验证、消融与防沉默（2026-11-17）

本次增加 `npm run snn:validation`：固定原图索引 **0–499 训练、500–699 验证、1000–1199 保留评估**，互不重叠。保留区也与上节使用的 1477–1676 测试区不同。所有候选先只用训练数据拟合 SNN 和读出、在验证集上比较；验证结果最高的可塑候选进入保留评估，遇同分取预设列表靠前者。随机模型始终作为对照，不参与可塑候选选择。保留集在选择后才生成；但下面多组实验重复使用了同一保留区，因此它**不是每组都全新独立的确认集**，不能再根据它挑超参数后称其为最终盲测。没有按书写者切分，数据规模仍小。

实验分别使用输入事件种子 `1592594996` 与 `77`。种子改变的是泊松事件流和预测器的种子；**卷积初始化种子固定、图像切分相同**，因此这不是独立模型初始化或独立划分的多种子置信区间。候选一轮无标签训练，读出仍是监督 softmax 且不向 SNN 回传误差。

验证集诊断中，按单通道在全部验证图像、所有位置和时间步的平均发放率 `<0.001` 记作“低活动”（不是证明神经元永远不发放）。固定中心规则的三个权重学习配置，在两个种子下 **L2 均为 32/32 个低活动通道**，尽管准确率看似还能达到 79%–84%；仅阈值调节与随机基线是 0/32。训练结果中也记录每通道发放率、阈值和核平均两两余弦；这些只是诊断，不能证明核已成为边缘或笔画检测器。

## 类别调制 WTA 与 CM 模型文件（本次迭代）

### 训练方式

`npm run snn:class` 默认读取上一节种子 77 的 `threshold-only.dense.json`：它先前在训练集上学到了通道稳态阈值，91.0% 是该模型在索引 1000–1199 上的稠密结果。类别调制阶段**保留并冻结这些阈值**，不做第二遍阈值自适应，避免把额外阈值漂移与权重学习混为一谈；冻结不意味着新的数据流上持续稳态适应。作为对照，91% 基底的参数和读出都保留原样。

新增 `ClassModulatedPlasticity`：

1. 对每个空间位置的发放通道做循环起点 WTA；赢家将其感受野的突触前脉冲累积为分通道/空间池的局部 eligibility trace。观察时不读取类别。
2. 样本结束用**冻结的原读出**先预测；得到真实标签后，以读出层真类与竞争类的系数差、标准化尺度构造有界的带符号第三因子。误判时竞争类是预测类、强度 1；预测正确时用最强的其他类、强度 0.15，避免原读出对训练集全对时零更新。
3. 正负第三因子分别对赢家的中心化局部相关作 Hebbian/Anti-Hebbian 调制；按输出核保持范数，更新后重建上界缓存。标签参与调制但不作为推理输入。这里的核内归一和基于已训练读出系数的类信号是工程近似，不声称严格生物真实性；不是时间差 STDP，也没有通过 SNN 传播梯度。
4. 在相同 500 张训练图上再训练一遍突触，之后冻结 SNN，**单独重新拟合监督 softmax 读出**（读出仍使用梯度，但不反传到 SNN）；最后在冻结网络上用训练图训练 CM 的稠密教师。与基底相比训练步骤及成本并不相同。本实验不是前序在线评估，完整训练样本已用于训练基底读出，重放过程中误差数量为 0，并不能表明泛化无错误。

预设学习率 0.03 和 0.1，在原验证区 500–699 选最高验证准确率的可塑候选，同分取 0.03；与基底相比验证分数不提升时保留基底为推荐模型。最终评估区 1000–1199 已用于上一节，因此这里是**复用评估集的探索性对照**，不是全新盲测；准确率仍未达到 92%–95% 目标。

| 模型 | 验证稠密准确率 | 复用评估稠密准确率 | CM 70% 准确率 | CM 总算术比 | 评估集 L2 低活动 |
|---|---:|---:|---:|---:|---:|
| 稳态阈值基底（推荐） | 86.0% | 91.0% | 90.0% | 56.1% | 0/32 |
| 类别调制 WTA 0.03（可塑候选） | 86.0% | 90.0% | 90.0% | 56.4% | 0/32 |
| 类别调制 WTA 0.1 | 86.0% | 未评估 | 未评估 | — | — |

学习率 0.03 的一次训练中，两层权重 RMS 改变量为 0.002287 / 0.000320；发生 23,999 次核更新，正/负类信用分别覆盖 99,034 / 95,225 个赢家池条目。计数的是条目/核更新，**不是**独立突触数。原读出重放训练集时 500 次全对，第三因子实际均由“真类对第二类”的弱信号产生。结果证明这次两层权重确实改变且没有观察到上次 L2 低活动，但验证准确率持平、复用评估稠密准确率下降 1 个百分点；样本量只有 200，不能据此断言收益或退化显著。CM 70% 的总算术比只是在旧计数口径下减少约 44%，**不是**墙钟提速，也不包括教师、局部更新、读出训练、内存与序列化开销。

回执：[`experiments/snn-class-wta/results.json`](../experiments/snn-class-wta/results.json)。`--quick` 仅用很少样本验证流程，而且默认基底早已见过这些图，烟测分数不具备评估意义。

### CM-v2 模型与单样本推理

新格式 `ucz-snn-cm-v2` 将稠密网络/阈值/读出与**指定 group 的已训练 CM 状态**一起保存：配置、计数器、混合器权重、APM、位置哈希、脉冲历史以及统计量。大整数数组采用固定小端 gzip/base64 存储并在加载时检查长度。只允许在完整样本/步骤边界保存；推理复用的是教师结束后的状态，`snn:predict` 默认**冻结预测器及历史，不在线学习**，所以每次命令从同一状态开始。v2 记录训练所用的泊松编码种子；旧 `*.dense.json`（v1）继续支持稠密推理，但不能假装有训练好的 CM，传 `--mode cm` 会报错。此格式不是完整训练断点，不保存局部 eligibility、其他粒度预测器或分类训练器状态。

两个实际训练模型：

- [`intrinsic-baseline.cm.json`](../experiments/snn-class-wta/intrinsic-baseline.cm.json)：91% 稠密基底 + group=8 的 CM。
- [`class-wta-0.03.cm.json`](../experiments/snn-class-wta/class-wta-0.03.cm.json)：类别调制后的模型 + 自己的 group=8 CM。

```bash
npm run snn:class -- --out experiments/snn-class-wta
npm run snn:predict -- --model experiments/snn-class-wta/intrinsic-baseline.cm.json --index 1002 --mode cm
npm run snn:predict -- --model experiments/snn-class-wta/class-wta-0.03.cm.json --index 1002 --mode cm --budget 0.5
npm run snn:predict -- --model experiments/snn-class-wta/intrinsic-baseline.cm.json --index 1002 --mode dense
npm run test:snn
```

`--budget` 是候选预算，不保证脉冲无损；它可以覆盖保存的 0.7 默认预算。输出包含预测、数据集真值、logits 和估算账本；`denseMacs` 从卷积几何计算，未额外执行稠密前向。仍只支持仓库数字数据及泊松编码，覆盖 `--seed` 会改变输入事件流。每个验证脚本的新运行也会在保存旧稠密文件后保存 `*.cm.json`；早先回执目录中的旧 v1 文件不会自动升级。测试验证序列化前后的预测概率、脉冲、特征、账本、进一步在线学习以及 CLI 单样本结果一致，并检查旧文件不能用于 CM。

## 1200 张与类别原型的后续实验

训练、增强、层间布局修正、原型通道诊断及 CM 对照见 [SNN_PROTOTYPE.md](SNN_PROTOTYPE.md)。单次测试中稠密模型为 98.0%，但验证为 89.0%、三通道直接分类仅 12.0%；CM 70% 为 96.0% 且算术比 62.8%，尚未同时达到目标精度和 50%–70% 的节省。新旧数据划分与模型布局不同，不应拿旧 91% 数字直接归因比较。

## 第二阶段：Stream Agent 初步结果

[流式先预测后学习与类增量实验](SNN_STREAM.md)：对照和 CM 熵门控在第一阶段后旧类测试为 91.3% / 82.5%，第二阶段后均为 0%。当前简单门控没有解决灾难性遗忘；冻结 SNN 的无标签阈值曾接触完整流，不能称为严格零预训练。第三阶段尚未实现。

## 第三阶段：在线字节序列生成探索

已实现从空 CM 状态逐位预测/学习的循环 LIF + CM 原型和无脉冲上下文对照，详见 [SNN_SEQUENCE.md](SNN_SEQUENCE.md)。4 KiB 输入后能够按位采样字节，但样本存在乱码且内容不连贯；两个示例的预测码长反而弱于纯 CM，尚不能证明脉冲贡献或可靠文本生成能力。

### 多尺度后续对照

见 [SNN_SEQUENCE_V2.md](SNN_SEQUENCE_V2.md)：莎士比亚留出从纯 CM 的 3.7945 降至 3.7374 bit/byte，但固定脉冲相位的补充专家更优（3.6647），不能将提升归因于脉冲状态。已见字节支持集消除了示例中的未见单字节，但无法保证多字节编码或 OOD 序列有效。

### 粗相位残差对照

见 [SNN_SEQUENCE_COARSE.md](SNN_SEQUENCE_COARSE.md)：在固定相位底座上添加两位脉冲状态残差，莎士比亚 / 代码冻结留出分别为 3.6213 / 3.8680 bit/byte，均低于原底座的 3.6647 / 3.9095。但同容量的固定残差消融分别为 3.6193 / 3.8703，因而不能认为该收益已证明来自脉冲相位。
