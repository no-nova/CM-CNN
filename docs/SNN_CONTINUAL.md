# 类隔离与在线原型：无原图回放的类增量实验

## 结果

使用三个**流内顺序**种子 77、78、79，固定相同 SNN、数据划分、泊松编码和超参数。表中为三个种子的均值（括号为最小–最大），百分数均按准确率计；遗忘为第一阶段后的旧类准确率减去第二阶段后的旧类准确率，单位是百分点。

| 方法 | 全流先预测准确率 | 第一阶段后旧类测试 | 第二阶段后旧类测试 | 旧类遗忘 | 第二阶段后新类测试 | 第二阶段后全类测试 |
|---|---:|---:|---:|---:|---:|---:|
| 在线 Softmax | 57.7% (57.3–58.1) | 83.2% (74.8–91.3) | 0.0% | 83.2 | 76.0% (72.2–78.4) | 36.8% (35.0–38.0) |
| 原熵门控 Softmax | 59.9% (59.8–60.2) | 78.0% (73.8–82.5) | 0.0% | 78.0 | 89.3% (84.5–95.9) | 43.3% (41.0–46.5) |
| 无梯度 EMA 原型 NCM | 83.8% (83.1–84.1) | 85.4% (84.5–86.4) | **71.8% (70.9–73.8)** | 13.6 | 90.7% (90.7–90.7) | 81.0% (80.5–82.0) |
| 原型锚定、行隔离读出 | 85.0% (84.0–85.6) | 83.8% (83.5–84.5) | **70.2% (68.9–72.8)** | 13.6 | 93.5% (91.8–94.8) | 81.5% (81.0–82.0) |

测试集旧类有 103 张、新类 97 张，总计 200 张。若把“保留率”定义为 `第二阶段旧类准确率 / 第一阶段旧类准确率`，NCM 三个种子分别是 82.0%、86.4%、83.9%；锚定读出分别是 82.6%、82.6%、86.2%。旧类没有完全保留，但两个新方法避免了对照中的全灭。锚定相对 NCM 的新类、全类差距仅是小样本单次设置的观察，不能断言具有统计显著性，也不能把它归因于锚定项本身：两者的决策函数不同，尚无消融。

### 为什么冻结仍会遗忘？

实验对每个种子逐元素核对：在 5–9 阶段，0–4 的 NCM 原型、锚定模型原型和权重行及计数都**完全不变**。然而新增类的原型/权重加入同一个 10 类竞争，旧图仍可能被判为新类。单独的只读诊断将第二阶段模型的候选类别限制为 0–4，得到的旧类准确数与第一阶段完全一致；再恢复全部 10 类，分别少了：

| 种子 | NCM 被新类抢走的原本正确旧图 | 锚定读出被新类抢走的原本正确旧图 |
|---|---:|---:|
| 77 | 16 / 103 | 15 / 103 |
| 78 | 12 / 103 | 15 / 103 |
| 79 | 14 / 103 | 12 / 103 |

只看 0–4 的诊断**使用了任务身份**，不是报告的类增量性能；真实测试始终允许全部已见类别竞争。它说明本次残余下降是新旧类别边界竞争，不等于旧类行遭到负梯度擦除。详见 `diagnostics.json`。

## 重现与使用

```bash
npm run snn:continual -- --out experiments/snn-continual
npm run snn:continual -- --seeds 77,78,79,80,81 --out experiments/my-continual
npm run snn:continual -- --quick --seeds 77 --out .diag-state/continual-smoke
npm run snn:continual-check -- --out experiments/snn-continual
npm run test:snn
```

结果存于 [`experiments/snn-continual/results.json`](../experiments/snn-continual/results.json)，包括固定超参数、三份每样本轨迹、每阶段每类分子分母、结果汇总和旧行冻结检查；每个 `agents-seed-*.json` 包含两种新方法和两个对照的最终状态及特征模型 SHA-256。`snn:continual-check` 加载同一特征模型和状态，重新提取测试特征并验证只限制旧类候选的诊断；默认不会改变模型或结果文件（只写入 `diagnostics.json`）。种子只改变每阶段样本顺序，不改变分区、泊松流或网络初始化。实验用内存缓存一次冻结特征供多组和多个种子共用；这只是离线实验优化，在线分类器自身不持有历史图片、历史特征或回放缓冲区，测试/验证特征不用于更新。`--quick` 是流程测试而非跑分。

在线模型可以单样本只读推理：

```bash
npm run snn:continual-predict -- --state experiments/snn-continual/agents-seed-77.json --method ncm --index 1700
```

显式提供标签才会更新，建议先复制状态文件；`--method anchored` 选择另一方法：

```bash
mkdir -p .diag-state
cp experiments/snn-continual/agents-seed-77.json .diag-state/continual-agent.json
npm run snn:continual-predict -- --state .diag-state/continual-agent.json --method anchored --index 1700 --label 3 --update
```

示例标签 3 不保证是该图真值。预测永远先于标签反馈；不传反馈时预测不更新 CM 或任何模型状态。显式反馈后用原子替换写回对应方法，不影响同一文件的其他方法；不要并发写同一文件，勿用测试集标签更新后仍当无泄漏测试。快照保留该方法的类别向量、计数和 CM 状态，并关联完整特征模型文件的 SHA-256；不保存待反馈样本。引用路径相对于执行时的工作目录，模型文件必须存在且哈希匹配。

## 同一协议与方法细节

复用 [SNN_STREAM.md](SNN_STREAM.md) 的全部 1200 张流图和 200/200 验证/测试图、0–4（594 张）→5–9（606 张）、每阶段同样的种子洗牌和 432 维归一 SNN 特征，四组同时对每张图先预测并计分、随后才读取该图标签。两种原对照直接使用原 `StreamAgent` 和原超参数；seed 77 两组的完整 1200 条预测和样本顺序与上轮结果逐条相同。无任务 ID 输入、无历史原图/特征重放。每阶段末无更新评估验证及测试；测试没参与超参数选取。第一次预测时四组均按类别 0 打破全零/无类别的平局。

两种原 Softmax 对照始终保留 10 个 logits（包括尚未出现过的类别）；两种新方法没有未见类别的表示，**仅有收到过标签的类别参与预测**。它们不知道当前阶段或测试样本的类别，第二阶段全部类别见过后即是 10 类竞争，但冷启动候选规则不完全一致，这是对照解释的限制。NCM 和锚定模型彼此独立维护相同结构的 CM，并按相同输入顺序更新；实验逐样本检查其熵和惊奇度与现有熵门控组一致。

对 432 维单位特征 `x`，新方法使用同前的二值特征上下文 CM：先用历史计数预测当前样本特征，得到 `H` 和平均自信息 `S`，再在反馈后更新 CM。`eta = 0.03 + 0.12*min(1,S/2)`。每个类只持有一个 EMA 向量及计数：初次见类将原型设为 `x`，以后 `μy ← (1−eta)μy + eta*x`；其余 9 类严格不动。

- **NCM**：预测时在已见类中最大化 `cos(x,μk)`。整个分类器的原型更新没有梯度，不用读出训练或样本回放。
- **锚定 + 行隔离**：每类另维护一个单位长度权重行、无偏置；预测用 `5*cos(x,wk)`。反馈后，先更新当前类的 EMA，再使用已见类（含当前类）softmax 的 `py` 更新**仅当前类行**。更新方向为 `0.3*(1−py)*x + 0.15*(normalize(μy)−wy)`；若当前行对自身原型与最相似非 y 类原型的分数差小于 0.15，再加 `0.12*(normalize(μy)−normalize(μother))`。总方向乘以原 CM 熵/惊奇度和正确性门控系数（定义见 SNN_STREAM.md），随后对当前行归一化。旧类别行、旧原型及旧计数不会随其他类别被更新。该读出含当前类正向监督梯度与工程性锚定/边界校准，**不是完全无梯度**；没有对其他类应用 softmax 负梯度，也没有偏置。

原型占 `10×432×8 = 34,560` 字节的 Float64 值及少量计数；锚定读出额外有相同大小的行向量。各自还包含 CM 计数表和运行时临时向量；以上不含模型对象开销、冻结 SNN 或离线实验缓存。这里的 CM 是在线特征上下文混合器，**不是**用于纤维块计算节省的脉冲预测器。SNN 以无损 event 模式冻结运行，本实验没有测实际延迟、能耗或 CM 纤维块节省。

## 边界与后续

固定的 SNN 无标签阈值在整个 1200 张流图上预先适应过，因此这不是表征也完全因果的零预训练实验；该 SNN 不使用已训练读出，亦未用本实验验证或测试图更新。测试集此前用于项目实验且不是书写者隔离。三个种子共享一组测试图和 SNN，不能视为独立数据划分或总体置信区间。参数是实验前指定的一组，而非系统性的验证调参；未做 CM 惊奇度 vs 常数 EMA、锚定和边界项消融、相同分类器不同隔离策略等对照。

下一步可用独立书写者划分和更多顺序种子，同时进行上述消融；尤其研究不保存原图条件下的新旧类别边界校准，以改善剩余 13.6 个百分点的平均旧类下降。
