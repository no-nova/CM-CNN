# 固定相位底座 + 粗粒度脉冲残差

## 受控结果

严格沿用上一轮两份数据的前 4096 字节训练、随后 2048 字节留出。表中为 bit/byte，越低越好；数值未对留出集进行采样截断。三组从空状态逐位先预测再更新，每组使用相同的固定相位 CM 底座。

| 数据 | 指标 | 固定相位底座 | 底座 + 粗脉冲残差 | 底座 + 固定相位残差（匹配消融） |
|---|---|---:|---:|---:|
| Shakespeare | 训练流先预测 | 3.896297 | 3.840574 | **3.836441** |
| Shakespeare | 留出、参数冻结 | 3.664733 | **3.621312** | **3.619349** |
| Shakespeare | 留出、逐位在线学习 | 3.527442 | 3.483594 | **3.482230** |
| 代码 | 训练流先预测 | 4.113145 | 4.082643 | **4.078876** |
| 代码 | 留出、参数冻结 | 3.909544 | **3.867982** | 3.870289 |
| 代码 | 留出、逐位在线学习 | 3.497109 | **3.450888** | 3.453342 |

与用户指定的 `constantPhase` 底座相比，粗脉冲方案在 Shakespeare 和代码的冻结留出上分别降低 **0.043420** 和 **0.041563 bit/byte**，两项都严格更低。底座冻结留出值与 [上一轮结果](SNN_SEQUENCE_V2.md) 完全一致；单元测试还核对训练过程中全部底座计数表、支持集和状态完全一致。

**但这不证明脉冲状态的独立贡献。** 匹配消融加了同样的残差表与更新，只是把相位恒定为 0。它在 Shakespeare 冻结留出上比粗脉冲**低**约 0.001964 bit/byte，而在代码上比粗脉冲**高**约 0.002308 bit/byte，相当于 2048 字节总对数损失相差约 4.0 / 4.7 bit。两者的差异方向不一致且很小；主要改善也可能只来自额外的概率残差校准。没有统计把握称相位可靠有益。

留出数据与上一轮复用，用户请求和设计是参考旧结果提出的，故不是项目级全新盲测。两个连续片段也不是独立文档或足以代表语料的样本。参数是本轮实现前固定的一套，并非在这两个留出区上搜索得到；不能据此外推。结果文件还包含四个连续 512 字节留出窗口，窗口彼此相关，不能当作独立试验。

## 机制与因果性

- 直接复用 v2 `MultiscaleByteModel(false)` 作为共同底座。它包含原 CM 的全部精确上下文和两个 `prevByte + 固定相位` 平滑专家；不更改它们的桶、混合权重或学习规则。新的残差通过独立的预测钩子叠加；底座始终在每位真值出现之后独立学习，绝不读取残差专家的预测结果。
- 从已有 12 神经元结构状态提取严格 **2 bit / 4 状态**：慢单元 `slow[3] >= 128` 一位；8 个快单元的上一步脉冲数是否至少为 2 另一位。状态只使用先前完整字节，原结构的可控衰减、阈值及高频字节事件机制见 [SNN_SEQUENCE_V2.md](SNN_SEQUENCE_V2.md)。这些比特只是固定阈值的工程特征，并不证明学到了词边界。
- 每个位的残差表键仅为当前字节**已观察的高位前缀**与上述 2 bit 相位，不含 `prevByte`，没有把精确字节和脉冲相位做笛卡尔积；表使用直接索引，不发生哈希碰撞。可用的有 255 个前缀 × 4 状态；每格维护计数 `n` 和底座预测残差和 `g`。
- 预测时，若底座概率为 `p0`，使用 `delta = clamp(2*g/(n+6), -1, 1)` 并输出 `sigmoid(logit(p0)+delta)`。空桶（或残差和恰为零）严格返回原 `p0`。当这一位真值 `y` 到达后，才做 `n += 1; g += y-p0`；计数到 1024 后对 `n` 和 `g` 折半。这里 6 是计数意义上的收缩常数，2 是固定增益，输出最多移动 1 个 logit 单位。是额外的在线残差校准，并非训练脉冲突触；没有预训练权重或端到端反向传播。
- 固定残差消融完整保留同一个底座、相同大小的表、公式和更新，但对每一位把相位强制为 0。训练流中粗相位在 Shakespeare 的四格出现次数为 1240 / 1559 / 556 / 741，代码为 1375 / 1536 / 593 / 592；粗方案分别激活 286 / 379 个残差桶。四个状态都被使用，但**被使用不等于有预测增益**。

留出冻结模式的真实字节仍推进上下文和脉冲状态，但不更新任何概率表；留出在线模式在对每位计分之后更新。结果中的损失是 teacher-forced 理论对数损失，不是实际压缩大小，也不是自由生成文本的质量指标。

## 运行、恢复和输出

```bash
npm run snn:sequence-coarse -- --out experiments/snn-sequence-coarse
npm run snn:sequence-coarse -- --input scripts/diag/inspect-structure.mjs --out experiments/snn-sequence-code-coarse

# 用自己的连续字节文件，训练和留出长度可改；--eval-bytes 0 表示不做留出评估
npm run snn:sequence-coarse -- --input path/to/input.txt --train-bytes 4096 --eval-bytes 2048 --out experiments/my-coarse

# 恢复训练结束的 v3 模型；--input 可省略；默认使用已见字节支持集截断
npm run snn:sequence-resume -- --model experiments/snn-sequence-coarse/model.json \
  --support observed --generate-bytes 512 --seed 17 --out experiments/my-coarse-resume
npm run test:snn
```

`model.json`、`constant-phase-model.json`、`fixed-residual-model.json` 分别为粗相位、原底座和匹配消融；支持继续读入新字节或从保存状态采样。`snn:sequence` 原入口仍运行 v2，本次实验独立于已有默认流程；`snn:sequence-resume` 保持对 v1、v2、v3 状态的支持。默认生成三组配对样本，含无截断和已见字节支持集两种；只推进生成上下文，不用生成字节训练计数表。莎士比亚截断样本中没有未见字节且本次三份均为合法 UTF-8，代码截断样本三份仍非合法 UTF-8；支持集不保证字节组合有效，也不保证生成内容连贯。
